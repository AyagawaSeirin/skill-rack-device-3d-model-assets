# 几何、材质和标识

## 写实外观是硬性要求

原版模型、写实生图参考和最终预览都以同型号同配置实物为视觉基准：已知外形、比例、凹凸、孔壁、接口布局、颜色、反射及标识应一致。拒绝动画片/卡通材质、描边、插画色块、玩具比例、夸张圆角和以演示为目的的造型简化。存在材质与形状偏差时按实物修复，不能把“数量正确”“拓扑通过”或“看起来精致”当作写实验收。

在相近观察方向和可解释的中性光照下对照真实照片，区分实物材质与拍摄环境的影响。转台或相机运动可以用于检查，但不改变设备的写实风格；示意草图须明确用途，不能替代写实模型/预览交付。

## 组件与真实结构

接手已有模型时，先检查 unit scale、父子变换及毫米参数是否已换算；保持原坐标，不因修复某个部件重复缩放整机。

用参数化的分段操作组织主壳、左右耳片、盘架/业务接口、管理接口、风扇、电源、紧固件和标识。主文件保留可编辑层级；重复件可共享网格，带不同文字/UV 的实例要先单用户化。显式区分模块数量与内部元件数量，避免给一组转子都打上 fan_module 标签。

正常盘架包含框架、把手、释放机构与可见深度；正常空端口包含金属笼、孔口、导向/接触件及合理的内部挡止。黑色来自遮挡和材料，不能用无厚度黑片替代全部腔体，也不能透过端口看穿整个机身。隐藏结构只做到解释可见深度所需，不虚构无依据的精密 PCB。Console/RS232 是功能或协议标识，不能据此直接画 DB9；RJ45、USB 等实际连接器形状和方向以当前设备资料为准。

钣金先有厚度、折边和实际装配缝，再处理小倒角。不要过度圆润、等比例加粗把手或给机身添加发光装饰。一个连续面板有多组开口时，优先构成连续实体；多块贴片在同一平面相互覆盖容易产生黑线和闪烁。

Boolean 后检查切除范围、剩余壁厚、内面、重复面与短边。小倒角不能吞掉细孔。机械接触、可动间隙和刻槽不是都要焊在一起；正体积检查也不能代替明显外部穿模的目视检查。

## 挂耳和开孔

先确定实际安装套件、端口端/另一端位置、弯折方向、固定螺钉与孔型；不把两套耳片孔位拼接，不把服务器提手移植到交换机。外部导轨和机柜立柱通常不属于设备总深，若需要则单独集合、单独测量。

圆孔、长圆孔和方孔分别建真实切除，孔壁连接板的前后表面；这样的耳板可以是封闭流形。金属使用 OPAQUE、Alpha 1、Transmission 0 和正常背面剔除。正反面都能看到是因为实体外表面和法线正确，不是靠 doubleSided 修补。

把螺钉删除只允许发生在隔离测试副本。正式装配中，空孔背后可能是背景、螺钉或机身；需要三个不同预期，不能把它们统一测成 Alpha 0。详细射线与像素测试见 [执行与验证](execution-and-verification.md)。

## 弯管的截面方向不能跳变

Cisco 电源拉手曾在弯角产生扭折：扫掠算法按切线与 Z 的夹角，突然从 Z 参考轴切换到 X，导致相邻截面旋转 90°。增加细分或全局平滑无法修复这个结构原因。

对平面路径可采用固定平面法向作为截面的一条基向量，再与路径切线求另一条；例如路径在 YZ 平面时可用固定 X 方向。任意三维路径需要连续标架（如平行运输），避免独立为每段选择不连续的参考轴。近反向切线和退化段要单独处理。弯曲半径与管半径合理分离，检查弯角是否自交、扭转及端盖法线。

修复后用掠射/高光特写查看连续性，再测拉手最外端，避免在修美观时改变整机总深。历史的半径、分段数和表面材质都不是通用默认值。

## 法线：平板与弧面分开

Dell 穿孔钣金的星状反光来自平面分裂法线偏斜。检查几何面法线与循环/分裂顶点法线的夹角，只比较预期共面的区域；小倒角和圆管允许随几何变化。必要时重建平板的硬边/分裂法线，保留真实圆弧平滑。

按当前 Blender 版本检测 mesh/corner normals API，不复制旧版本方法名后假定执行成功。修改共享网格会影响全部实例。先记录代表物件和共享使用数，再一次性修复并检查各处。

一个相当大的三角形也可能属于圆管；不能仅以面积决定它必须是平面。初次检查如果选错对象或遗漏独立面板，应修正测试范围并说明，不能把真实实体失败改成“允许开放”来过关。

## 材料与照明的比较条件

颜色纹理使用 sRGB；粗糙度、法线等数据图使用 Non-Color。微纹理有物理铺设尺度，幅度从轻微开始；粗糙度/法线过强会把镀锌板变成花岗岩。黑塑料应保留暗部层次，但不要靠抬曝光把它变成灰块。

记录一个中性灯光、色彩管理和相机基线。Material Preview 明确使用 Scene World/Scene Lights 或有记录的环境，不能拿未知默认 HDR 的反射色当基材错误。实际检查 Solid、Material Preview 和最终渲染；实时 AO/反射与 Cycles 间接照明不同，需说明差异，不要求像素完全一致。

机壳和耳片默认不透明、无透射，颜色贴图 Alpha 不连接基材透明度。真实玻璃、透明贴花或工作指示灯仅在证据支持时单独处理；不能让例外影响整个金属外壳。离线程序纹理若不能随 glTF 导出，应烘焙为标准纹理并复查导入结果。

Blender 场景曝光、灯具瓦数、AO 距离、法线强度、采样数和 clip 范围都要按当前米制尺度与渲染器确定。过去使用过的数值只是经验示例，不是所有设备的配方。颜色管理可能把线性白背景映射为浅灰；按实际输出描述，不声称 RGB 255。

## 标签、UV 和持久化

清晰可辨的 Logo、型号、端口编号可以独立几何或 UV 重建；打印微字不能靠放大或强对比恢复，错误投影还可能造成拖影。尽早寻找清晰铭牌，保留真实源分辨率限制；不要用 AI 微字替代它。

投影照片烘焙为标签时，分别命名输入 UV 与输出 UV，明确哪个节点读哪个坐标、哪个层为 active/render。删除 UV 层会使此前持有的 RNA 引用失效；删除后按名称重新取得对象，重新绑定所有 UV Map/Normal Map 节点，不沿用旧引用。验证每个引用的 UV 名存在。

从后部拍摄的顶盖标签有时需要双轴旋转或正确的四点投影；仅水平翻转以便“读得顺”会改变左右语义。用不对称符号、色块、源图角点及世界阅读方向交叉核对。正缩放只是必要条件，不能证明图片没被镜像。

墨层/贴花与基板的间距应小而合理。测量最终世界坐标的真实间距，同时选择适合米制设备的近远裁剪面，既避免 Z-fighting 又不悬浮。Dell 和 Cisco 曾使用不同量级的间距，不能直接复制某一次偏移值。

保存、关闭/重开主文件后再检查 UV 和打包图片；随后在实际 GLB 导入场景中再检查。当前 GPU 缓存里标签正常不算持久化通过。

## 转换、三角化与共享网格

文本/曲线转网格后检查端盖、重复面、退化三角形和松散边。实体通常需要预期闭合和正体积；墨层/标签可以是明确标记的开放表面，但不能含零面积面。清理退化面不能顺带封死字形孔洞或真实通孔。

必要时在导出前显式三角化，避免 glTF 另选对角线产生退化面。应用镜像等会影响法线的变换，检查世界矩阵行列式及最终视觉方向。glTF 因 UV/硬边拆点是正常行为，闭合检查在诊断副本按小于最细真实间隙的容差焊接；不要修改正式导入网格来消除这种拆点。
